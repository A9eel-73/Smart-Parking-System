# Smart Parking System using IoT and Fog-Cloud Integration
Capstone Project: An end-to-end Smart Parking System integrating IoT microcontroller sensors with Fog-Cloud architecture and a real-time mobile interface.


## 📌 Overview
This project presents an integrated Smart Parking System designed to optimize parking management and reduce urban traffic congestion. The system utilizes microcontroller-based IoT sensors to monitor real-time parking spot availability and leverages a hybrid Fog-Cloud computing architecture to process data with minimal latency.

## ✨ Key Features
* **Real-Time Spot Monitoring:** Microcontroller hardware continuously detects occupancy status.
* **Fog-Cloud Architecture:** Ensures local low-latency processing combined with centralized cloud database synchronization.
* **Mobile Application:** Provides users with live parking availability updates and navigation assistance.

## 🛠️ Technologies & Tools Used
* **Hardware & IoT:** Microcontrollers, Ultrasonic/Infrared Sensors
* **Cloud & Backend:** Cloud Database Sync, Fog Node Integration
* **Mobile Frontend:** Mobile App Framework
* **Languages:** C/C++ (Embedded Systems), Mobile Application Code
